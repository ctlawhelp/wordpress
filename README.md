# CTLawHelp WordPress Plugins

Custom WordPress plugins for CTLawHelp.org — a free legal information website serving low-income Connecticut residents, operated by Statewide Legal Services of Connecticut.

## Plugins

| Plugin | Description |
|--------|-------------|
| `ctlawhelp-interactive-guides` | Interactive legal guides |
| `ctlawhelp-legal-aid-articles` | Core legal article post type and management |
| `ctlawhelp-menu-icons` | Menu icon support |
| `ctlawhelp-nsmi-landing` | NSMI taxonomy landing pages |
| `ctlawhelp-permalinks` | Custom permalink/URL management |
| `ctlawhelp-pii-masker` | PII masking for privacy |
| `ctlawhelp-sidebars` | Sidebar management |
| `ctlawhelp-snippets` | Reusable content snippets |
| `ctlawhelp-tax-breadcrumbs` | Taxonomy-based breadcrumbs |
| `ctlawhelp-tax-breadcrumbs-drupal` | Breadcrumb compatibility for Drupal migration |

## Migration Context

This repo supports an ongoing migration from Drupal to WordPress. See the full migration summary in the workspace for details on the content model, import pipeline, and NSMI taxonomy system.
